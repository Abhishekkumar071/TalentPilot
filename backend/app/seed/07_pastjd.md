# Past Job Description Example - Senior Backend Engineer (2025)

Title: Senior Backend Engineer (L3), Backend Platform Team, Noida (Hybrid)

About the role: You will design and scale the services that track 2 million shipments every day. You will own APIs end to end, from design docs to production monitoring, and mentor two junior engineers.

Responsibilities: design REST and event-driven services in Python/FastAPI; model data in PostgreSQL; build Kafka consumers; improve p99 latency; write tests and design docs; participate in on-call; review code.

Must have: Python, FastAPI or Django, PostgreSQL, REST API design, Docker, Git, 3+ years building production backends.
Nice to have: Kafka, Kubernetes, AWS, Redis, observability tooling.

This posting received 140 applications in 10 days; the best-performing channels were LinkedIn and employee referrals. Candidates responded well to the clear salary range and the real-world problem statement.
