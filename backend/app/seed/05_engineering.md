# Engineering Teams and Tech Stack

Backend platform team: builds APIs and microservices for shipment tracking and routing.
Stack: Python (FastAPI, Django), Node.js (NestJS), PostgreSQL, Redis, Kafka, Docker, Kubernetes on AWS (EKS, RDS, S3, SQS). REST and gRPC APIs. CI/CD with GitHub Actions. Observability with Grafana, Prometheus and OpenTelemetry.

Frontend team: React with TypeScript, Next.js, Tailwind CSS, React Query, Playwright tests. Design system built in Storybook.

Full stack (Customer Apps) team: owns customer dashboards end to end using React + TypeScript on the frontend and Node.js / Python services on the backend.

Mobile team: React Native driver app used by 50,000 delivery partners, offline-first.

Data and ML team: route optimisation and ETA prediction models using Python, pandas, scikit-learn, PyTorch, Airflow and Snowflake. LLM-powered support assistant built with LangChain.

DevOps / SRE team: Terraform, Kubernetes, ArgoCD, AWS cost optimisation, 99.95% uptime SLO, on-call rotation (one week every 6 weeks, compensated).

Engineering practices: code reviews for every PR, 2-week sprints, design docs for major changes, test coverage above 75%, blameless incident reviews.
