# Career Framework and Related Roles

Role families and adjacent roles (used for internal mobility and for broadening job postings):
- Backend Engineer <-> Full Stack Engineer <-> Platform Engineer
- Frontend Engineer <-> Full Stack Engineer <-> Mobile Engineer (React Native)
- DevOps Engineer <-> Site Reliability Engineer <-> Platform Engineer
- Data Analyst <-> Data Scientist <-> ML Engineer
- QA Engineer <-> SDET (Software Development Engineer in Test)

Level expectations:
- L1/L2: delivers well-scoped tasks, writes tested code, learns the codebase.
- L3 Senior: owns features end to end, mentors juniors, designs services.
- L4 Staff/Lead: owns a system or team roadmap, drives cross-team technical decisions.

Remote work policy: roles are hybrid by default. Fully remote within India is allowed for L3+ engineering roles and hard-to-fill roles with VP approval. Remote employees visit the office one week per quarter (travel paid).
